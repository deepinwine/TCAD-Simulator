# 八类结构工艺与步骤类型编辑

用户批准：新增步骤仅显示光刻、刻蚀、沉积、氧化、外延、去胶、CMP、掺杂；
右侧允许将已有步骤换成另一类型。继续参数化 Structure CAD，保留旧仿真配方语义。

## 用户流程

八类目录固定顺序，中英文切换；填充是沉积模式，平坦化显示 CMP，版图开口显示光刻。
初始晶圆移到项目设置入口，其底层初始化步骤保留，不删除用户数据。
项目设置经既有 `/api/recipe/export` 导出完整 Recipe，仅更改初始化参数和 domain，
再经原子 `/api/recipe/import` 应用；保留后续步骤、名字及元数据。
界面明确说明应用后旧几何与快照失效，需要重新构建；不采用两次独立 mutation。
右侧步骤类型下拉选择后打开候选配置，不立即改服务器；取消保持原步骤。
候选继承自定义名称与适用材料，不把厚度猜成刻蚀深度，不带不相关参数。
确认原子替换同一索引，后续状态失效；保存失败、非法输入或运行中不替换。
已有参数草稿在替换前明确处理：先等待保存队列，非法草稿禁止替换，不能静默丢失。

## 结构语义

- 光刻复用 Structure Pattern 及不可变 Mask Asset，不做光学曝光求解。
- 刻蚀复用深度与侧壁角；沉积复用新增膜厚，填充模式复用绝对高度。
- 氧化以目标氧化层厚度替换表面硅并向外增加氧化层，网格量化与适用边界明确；
  不通过温度、气氛和时间预测生长速率。
- 外延按目标厚度添加半导体，仅允许选定半导体表面及明确掩膜覆盖；不做生长动力学。
- 去胶移除 Photoresist，不误删其他材料。
- CMP 复用绝对高度截断。
- 掺杂在选定半导体区域、掩膜及表面深度内写入 species/concentration，
  不做注入散射、激活或扩散；浓度场保留真实数据，3D 可视化与材料身份分离。

新步骤仍注册于 PROCESS_STEP_FACTORIES，旧六类和旧仿真名称保持可导入、执行、导出。
React 仅呈现与发请求，几何/场写入在 Python；Viewer 不因换类型或语言重挂。
HTTP 演进加法兼容；替换通过 /api/step/set 可选 name 字段进行 detached candidate
校验及一次提交，不使用 remove + add。旧不带 name 的请求保持原行为。

## 验证

各类型有实际体素或浓度场断言；非法极值、类型及无目标操作原子失败；
替换索引、顺序、名称与后续快照失效经 HTTP 验证。前端覆盖八类目录、候选取消、
参数不误迁移、等待草稿、失败保留、语言与 Viewer 生命周期。运行旧五模块、
Structure 专项、前端全量、compile 和 grid128 基准，再独立规格/质量复审。
