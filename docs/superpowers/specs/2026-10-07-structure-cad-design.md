# 参数化半导体结构构建设计

用户决定（2026-10-07）：当前产品先交付输入参数得到三维半导体结构，暂停新增物理仿真功能。

## 架构与范围

继续使用 React、Python ProcessStep、ProcessModel 体素几何及 Three.js。新增明确命名的
Structure 步骤，通过现有 Recipe、执行、快照、预览与版图资产事务接口运行。
用户执行结构配方时不得调用 ViennaPS、刻蚀速率内核、光学曝光或热/电学求解。
既有配方保留原语义；结构构建入口加载纯 Structure 配方并说明几何分辨率。

第一轮包含六种操作：

| 步骤 | 输入与含义 |
|---|---|
| Structure Wafer | 材料、厚度；从 Z=0 建立完整实心层 |
| Structure Deposit | 材料、厚度、全片或版图开口；在每列实际最高表面上垂直添加 |
| Structure Pattern | 程序化版图或不可变 Mask Asset/旧图片；直接定义二维开口，不曝光和显影 |
| Structure Etch | 材料、深度、侧壁角；从各开口列上表面移除目标材料，遇其他材料停止 |
| Structure Fill | 材料、绝对填充高度；将该高度以下的空隙填满，保持已有材料 |
| Structure Planarize | 绝对 Z 高度；切除该平面以上所有材料 |

## 几何语义

canonical 长度 nm、角度 degree；逐参数显示单位沿用 ADR-025。长度离散为最近体素层，
误差最多半个网格间距；正长度若离散为零必须报错。不得静默截断域外沉积。
侧壁角以基底平面为参考，90° 为垂直；0<角度<=90°，向下开口按 depth*cot(angle)
向内收缩，使用二维距离场构造几何坡面。近似精度由网格说明，不宣称物理准确。
刻蚀不穿透异材阻挡层、不跳过封闭空洞寻找埋层；深度是自每列起始表面向下的距离。
全片开口没有内部掩膜边缘，不应受人为域边缘斜坡影响。首轮只支持顶面 +Z 构建；
翻面模型明确拒绝以免错误方向。无目标材料/无有效开口导致零变更应给出明确错误。

所有输入完成校验与候选计算后才修改模型；执行失败沿用会话回滚。成功后维护空间字段、
height map、网格缓存及 canonical scene 的现有执行路径。Pattern 定义的 open_mask
必须在构建步骤间保留，不被通用高度重建意外重置。

## UI 与示例

工具栏增加「结构构建示例」入口，导入「Structure CAD — Trench」：100 nm Si 晶圆、
80 nm SiO2、线形开口、40 nm 垂直氧化层刻蚀、Cu 填充至 180 nm、平坦化至 160 nm。
domain 64×64×64、5 nm 网格。支持编辑版图并绑定 Structure Pattern。
参数面板显示中英文结构操作名称、单位与几何说明；构建纯 Structure 配方时运行按钮
显示「构建」并说明无物理仿真。界面不通过改标题伪装旧仿真配方。

## 验收

1. 上述示例通过正式 HTTP 导入、构建，得到 Si/SiO2/Cu 三材料非空网格与 STL。
2. 修改深度后，量测的沟槽深度按网格对应改变；90° 与倾斜侧壁有可量测差异。
3. 物理内核 mock 抛错时 Structure 配方仍成功；current_time_s 不增加。
4. Asset revision 与 SHA 精确绑定，旧图片/程序化开口可用，工作台能保存应用。
5. 输入无效、沉积超域、错误方向、无效开口在修改前拒绝并保留原模型。
6. 快照、撤销/重做、旧 Recipe 回归及语言/单位切换继续通过。

当前交付范围不包含多视图、可调面板、DOE、电学、热学或新增 Accurate 算法。
