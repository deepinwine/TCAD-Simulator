# 实体剖面与逐步隐藏预览

用户于 2026-10-08 确认：剖面不应把实心材料显示成空壳；每一步提供眼睛。
刻蚀、去胶等减材步骤隐藏时，查看跳过该步骤后重建的结构。

## 边界

- 配方、enabled、正式 model、执行状态、时间线、undo/redo、autosave 均不因眼睛改变。
- 所有眼睛使用一致语义：从独立预览执行序列排除该步，而非按材料 ID 隐藏。
  后续步骤在排除后的结构上依次重建；这不是逐步实体所有权系统。
- 初始化仍在项目设置，不作为可隐藏工艺步骤。
- 新开发只支持参数驱动 Structure 工艺；旧物理操作不能被静默近似或触发求解。
  不支持的预览返回明确错误，正式模型保留。

## 实体剖面

已定位 `viewerRuntime.applyClippingToMaterials` 只设置 clippingPlanes，没有切面。
复用现有 GET /api/slice 的真实 u16 材料截面，渲染与裁剪平面一致的切面。
已有响应字段 axis/index/index_max/shape/dtype/data_b64，不能改变旧契约。
前端只将材料 ID 映射为颜色/透明度，不推断或修改几何；空气透明，真实沟槽、孔洞保留。
X/Y/Z、多个同时开启的切面、边界位置、nm→µm、网格轴序及材料可见性都要验证。
异步结果绑定模型 revision 与裁剪位置，过期结果不能覆盖新切面。
切换剖面不重挂 Viewer、不重置相机；关闭与卸载释放纹理及材质。

## 眼睛与独立预览

每行独立可访问按钮，明确“在预览中隐藏/显示”，不能嵌套在步骤选择 button 内。
隐藏索引集合属于当前客户端视图，不写入配方；结构编辑、载入新配方、项目设置应用时清空。
与待应用类型候选互斥，不能暗中保存或丢弃候选。
预览覆盖当前正式执行截止点，而不是擅自执行尚未执行的后续步骤。
正式禁用步骤仍被跳过，眼睛不能将其重新启用。

后端用 detached Recipe/ProcessModel 复用既有 factories、mask assets、预检与执行协议。
新增隔离预览请求返回 session 内不可猜测 token，并对现有 manifest/STL/elements/slice
添加可选 preview_token。无 token 时保持正式模型旧行为。
预览须有体素/内存预算、session 隔离、容量和寿命限制；请求失败释放候选且不替换正式模型。
预览不调用正式 run/import/set_step、历史提交或 autosave 路径。
异步取消和过期响应不能改变当前画面；失败显示具体步骤及原因，允许重试或恢复正式视图。
关闭全部眼睛隐藏状态时直接恢复正式几何，不能运行或改写正式状态。
材质、剖面和真实掺杂场必须读取同一预览 token，禁止混用两个模型。

## 验收

实心硅剖面着色，真实孔洞不封死；三轴及组合裁剪一致。
相同材料的两次沉积可分别跳过，刻蚀隐藏确实改变隔离结构。
整个操作前后正式 recipe/model/fields/status/timeline/history/autosave 不变。
无支持的重建不得伪造成功；所有错误、过期、取消、恢复、资源释放有回归测试。
