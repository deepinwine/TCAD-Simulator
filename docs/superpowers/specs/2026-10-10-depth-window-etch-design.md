# 深度区间刻蚀设计

状态：所有者已确认书面规格并授权开始；先完成步骤眼睛功能，区间刻蚀尚未实现。

## 1. 目标与范围

在现有 Structure Etch 中增加「深度区间刻蚀」模式，用输入参数构造局部扩腔。
这是几何编辑，不预测温度、压力、时间、气体或刻蚀速率。

普通刻蚀保持现有深度和侧壁角语义。区间模式使用独立参数，不把侧壁角和方向性
同时作为轮廓约束。沉积的方向性与包覆设计不属于本规格。

先完成已在开发的步骤眼睛纯显示功能，再执行本功能的实现计划。不得用此次
新工艺行为替代、回放或触发眼睛显示过滤。

## 2. 参数与参考位置

| 参数 | 内部含义 | 校验 |
| --- | --- | --- |
| 刻蚀模式 | 普通／深度区间；旧配方缺省为普通 | 严格枚举 |
| 目标材料 | 仅去除此材料 | 既有材料校验 |
| 深度参考 | 开口入口平面／固定 Z | 严格枚举 |
| 起始深度 | 入口平面向下的距离 | 有限数，>= 0 |
| 终止深度 | 入口平面向下的距离 | 有限数，> 起始深度 |
| 下界／上界 Z | 固定 Z 模式中的全局坐标 | 有限数，下界 < 上界 |
| 刻蚀距离 | 由可接触表面向目标材料内的几何扩展尺度 | 有限数，> 0 |
| 方向性 | 0–100，0 为各向同性，100 为沿 -Z 定向 | 有限数，闭区间 [0, 100] |

默认参考为本步骤开始时开口入口平面。取当前掩膜开口内非空材料柱的最高实体
上边界作为同一个水平参考面；不是每列分别取局部表面，也不随本次刻蚀下降。
全空开口没有参考面，明确报错。界面显示此次解析的参考 Z，帮助理解起伏结构。

默认模式的有效高度带为 `[reference_z - end_depth, reference_z - start_depth)`；
固定 Z 高级模式直接使用 `[lower_z, upper_z)`，不再复用「深度」标签。
两种模式的非活动字段不能影响执行。

每个长度字段独立选择 nm／µm，序列化归一为 nm；方向性无长度单位。
参数不自动夹紧。越出模型域、区间颠倒、非有限值或体素精度不足均给出明确错误。
离散选择依据体素中心是否在区间内；界面解释网格分辨率，不能声称亚体素精确。

## 3. 可接触表面与扩展定义

步骤开始时冻结目标材料、掩膜开口、入口参考面和种子表面。种子仅来自从当前
掩膜开口能经已有空气通道到达的材料表面，并且位于指定高度带内。模型侧边或
封闭内部孔洞不能自动成为新的入口；其他材料阻挡，不能穿透它们到达目标材料。

没有可接触目标表面时拒绝执行，提示先创建通道或调整区间。不默默建立通道，
也不默认隔着完整上层材料挖腔。「任意几何挖腔」不在第一版范围。

令 `a = directionality / 100`，刻蚀距离为 `r`。采用一个确定的几何扩展规则：
半径 `(1-a)*r` 的球与长度 `a*r`、沿 -Z 的线段作 Minkowski 和。
因此最大向下距离为 `r`，最大横向及向上距离为 `(1-a)*r`：

- `a=0`：球形扩展，所有方向尺度相同。
- `a=1`：纯 -Z 扩展，无横向或向上扩展。
- 中间值：按上述规则连续改变，不声称等于真实工艺各向异性百分比。

仅接受在此扩展范围内、并与种子经目标材料／可达空气连通的目标体素；不能
跨越阻挡材料去删除它后方孤立的同材实体。严格裁剪到高度带，带外材料不变。
靠近带边界的球形扩展会被截断，UI 明示「区间受限的各向同性几何刻蚀」。

种子不在执行过程中重新无限扩展；刻蚀距离是整步预算，而非每轮重新获得的
距离。实现需要根据体素网格验证该定义，不能重复膨胀直到填满区间。

## 4. 架构、失败原子性与兼容

仍走 `Recipe -> ProcessStep.execute(model) -> ProcessModel`；Python 计算几何，
Three.js 只显示结果。复用既有掩膜、材料 ID、事务及 Structure 减材提交路径。
删除体素的显示 owner 清零，不新增步骤实体，不补造旧来源。

旧普通刻蚀的默认值、网格结果与序列化保持兼容。新字段是增量扩展，导入导出、
桌面／旧 WebUI、React、无界面加载均使用同一验证规则；不增加专用执行端点。
改模式不改变 stable step_id，执行后按既有流程失效后续状态和展示缓存。

在分配大型数组前检查域尺寸、工作区和距离范围，采用有界几何计算，不引入
无界体素两两距离矩阵。预算不足、非法参数或无有效删除均明确失败，当前模型、
配方执行状态、来源和历史不部分发布。新增算法位于 Structure 几何模块边界，
不顺带抽取或重写现有仿真引擎。

## 5. 界面

右侧检查器保留「刻蚀」类型，添加模式选择。普通模式仅显示现有字段；区间模式
显示参考方式、对应的两个边界、刻蚀距离、方向性和材料。方向性同时支持滑块
和数值输入，并明确两个端点语义。中英文对等，长度字段保持独立单位选择。

非平坦开口提示入口平面采用最高开口边界。严格区间限制与已有通道要求有说明。
只读的区间位置提示不能在前端计算或提交工艺几何。

## 6. 验收

- 普通模式旧配方 golden 结果不变，缺省新字段不改变行为。
- 先构造 300 nm 通道，再在入口下 100–200 nm 区间扩展 30 nm；区间外逐体素不变。
- 方向性 0、50、100 验证球形、中间规则和纯 -Z 扩展；0 与 100 不能仅换标签。
- 圆孔、矩形孔、多个开口、起伏表面、其他材料阻挡与封闭空腔均有真实 fixture。
- 没有通道、没有目标材料、空掩膜、带内无体素、非法区间和超预算有拒绝测试。
- 验证参考面冻结、固定 Z 等价区域、nm／µm 等价、旧字段在非活动模式不生效。
- 拒绝后 grid、display provenance、快照、历史及会话保持；成功后只清除被删来源。
- 新字段保存／加载、导入／导出、任意步骤类型切换与 stable step_id 保持有回归。
- TDD、项目基线、编译、grid128 性能、前端测试／类型检查／构建和真实浏览器验收；
  经规格与质量两阶段审查后才合并发布。
