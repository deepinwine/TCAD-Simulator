# 可理解的结构编辑工作区

用户已确认：参照粘贴 DOM 的左步骤、中大 3D、右检查器、底部时间线布局，
同时解决步骤一直叫 Deposit、不会编辑的问题，不只是换皮。

## 展示与编辑

默认步骤标题由操作、材料及关键尺寸组成，例如“沉积 · SiO₂ · 80 nm”、
“刻蚀 · SiO₂ · 深度 40 nm”；用户自定义名称优先，类型另作标签。
标题是派生展示，不覆盖持久化的 instance_name。材料支持服务端编号和名称。
点击步骤在右侧选中对应表单，中文操作说明和选中状态清晰；兼容英文、独立单位。
参数继续使用现有 schema/校验/保存队列。“应用并构建到此步”先保存全部有效草稿，
确认无残留或失败后再 run-until；非法参数、保存失败不得发运行请求。
显示“参数待保存”“已修改，尚未重新构建”，不得把旧几何当成最新构建。

## 添加与布局

添加操作先弹出配置表单，选择类型、材料/尺寸和可选名称，验证后确认添加；
取消不创建步骤。Structure 模式仅六种几何步骤，不暴露物理工艺。
复用现有 /api/init 和 /api/recipe/add，可加 optional 模板 metadata 及 params，
必须由服务器 schema 校验整个候选后一次添加；旧只传 name 的客户端保持行为。
若服务器未给模板，明确提供旧版添加入口，不伪造参数 schema。
桌面左宽约280px、右约320px，中心剩余空间；两分隔条可鼠标/键盘调宽且有上下限。
窄屏顺序步骤、3D、参数，避免不可见主要操作。工具栏分主操作/次要配方操作，
不把常用编辑控件挤到屏外。拖动面板不重挂 ThreeViewer、不丢参数草稿。
不实现多视图、停靠重排、物理引擎或未支持的参考页面按钮。

## 验收

自动测试：派生双语步骤标题/自定义名/numeric material；点击选中编辑；
新增配置取消不变、更改参数确认一次创建、非法候选原子拒绝；
草稿保存成功后运行/失败不运行/运行互斥/语言与单位保持；
分隔键盘调宽、有限尺寸、Viewer mount保持。完整前端、HTTP专项与AGENTS基线通过。
浏览器实测：载入六步示例、添加配置、改变深度并应用构建、检查右表单和3D更新。
