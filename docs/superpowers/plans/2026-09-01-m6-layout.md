## 任务 1：layout 包核心（归一化几何 + gdstk 适配器）

**文件：** layout/__init__.py、geometry.py、adapter.py；tests/test_layout_adapter.py

**步骤：**

1. 红灯（纯函数）：ROI 裁剪（凸矩形窗、任意多边形被裁/被切/全留/全弃）、
   bounds 计算、图层过滤。
2. 红灯（适配器）：write→read 回环保留多边形与图层；层级（cell 引用）展平；
   OASIS 回环；布尔 and/or/sub 结果面积；rasterize 矩形→栅格图案精确。
3. 实现 geometry（纯 numpy）与 adapter（gdstk 边界）。
4. 全套验证；提交 `feat(M6): 建立 LayoutAdapter 与归一化掩膜几何`。
